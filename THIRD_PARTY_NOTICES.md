# Third-party notices

QFT Markdown is distributed under the MIT license in [LICENSE](LICENSE), with copyright (c) 2026 Jie Ren. Third-party software and font files retain the licenses and copyright notices below.

The built-in interactive physics demonstrations, their static illustrations, and the isolated demo controller are original application code distributed under that same MIT license. They add no external plotting or 3D library dependency. Standalone HTML exports of documents and Markdown slides include the applicable application, reveal.js, and KaTeX notices with their bundled code. The standalone HTML download of an imported presentation has a collapsed **Third-party notices** section in its footer, outside the presentation: it always holds the application's MIT notice and adds, when that copy contains them, reveal.js (MIT), highlight.js (BSD 3-Clause), marked with Markdown, KaTeX (MIT), mhchem (MIT/Apache 2.0), and the SIL Open Font License with the font names (Source Sans Pro, League Gothic). A converted Slidev build's download carries the application's notice only. A portable Slidev package made with the packager also carries its own notices inside its compiled HTML.

The presentation library ships further browser code, loaded only when a presentation needs it: parse5 reads imported HTML without running it; the bundled reveal.js 6.0.2 distribution (its core, 14 themes, and the markdown, highlight, notes, search, and zoom plugins) and KaTeX 0.19.1 (with auto-render, mhchem, copy-tex, and its fonts) stand in for copies that presentations load from CDNs; esbuild-wasm converts Slidev builds in a Worker; and the CodeMirror HTML, CSS, JavaScript, JSON, and Markdown language packages power the presentation source editor. Some of these packages contain code or fonts from other projects, listed under [Components inside shipped packages](#components-inside-shipped-packages) with their license texts.

The optional Slidev starter at `public/slidev/interactive-physics.zip` includes Slidev, Vue, its theme, mathematical fonts, and their dependencies. Its archive contains a generated `THIRD_PARTY_NOTICES.txt`, and the compiled presentation embeds those notices so they remain present in standalone HTML exports. The reusable source and packager in `tools/slidev` use the application's MIT license; bundled dependencies retain their original licenses. Playwright is an Apache-2.0 development dependency used only for browser verification.
